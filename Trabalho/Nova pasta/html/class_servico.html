Detailed Description

Representa um post de serviço.

E um post, ou seja, herda os atributos e metodos da classe post Armazena uma descricao do servico Armazena numero de contato, id do perfil que o postou e o perfil da pessoa que postou Armazena o id desse servico que sera usado como a chave associada a ele no map que armazena todos os objetos dessa classe
