Detailed Description

Representa uma forma de armazenar e organizar os perfis da plataforma.

Armazena um map para guardar todos os perfis associados ao seu respectivo id/chave (atributo "idu" da classe Perfil) Armazena outro map para guardar os ids dos usuarios Armazena um set para guardar os emails dos usuarios Armazena, tambem, o id do usuario usado para fazer o controle dos dados nos maps
